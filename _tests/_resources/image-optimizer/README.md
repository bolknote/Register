# HDR regression fixtures

These are synthetic images; they contain no article or personal photograph.

- `hdr-base.jpg`: 32×18 RGB gradient, encoded by Pillow with a generated sRGB ICC profile.
- `hdr-gain-map.jpg`: 8×4 grayscale RGB gradient, used as a generic gain map.
- `hdr-base-p3.jpg`: a second synthetic 32×18 RGB gradient with the standard Display P3
  ICC profile generated by libultrahdr 1.5.0.
- `hdr-wide.jpg`: 3000×1688 uniform RGB base with sRGB ICC, a 512×288 gain map, and
  Adobe XMP / MPF headers generated by `_tests/_support/hdr-jpeg-fixture.mjs`.
- `hdr-retina.jpg` and `hdr-portrait.jpg`: outputs of the checked-in HDR optimizer, used
  to verify that the upload controller stores both JPEG layers without modification.

The fixture builder also constructs real ISO 21496-1 metadata, alternate XML prefixes,
rotations and invalid containers during the JavaScript tests. `PRIVATE_` markers are fake
creator/comments used to verify metadata removal.
