# System 1 theme assets

The PNG files in this directory were exported from the system resources of macOS:

- `finder.png` — `/System/Library/CoreServices/Finder.app/Contents/Resources/Finder.icns`
- `folder.png` — `/System/Library/CoreServices/CoreTypes.bundle/Contents/Resources/GenericFolderIcon.icns`
- `document.png` — `/System/Library/CoreServices/CoreTypes.bundle/Contents/Resources/GenericDocumentIcon.icns`
- `trash.png` — `/System/Library/CoreServices/CoreTypes.bundle/Contents/Resources/TrashIcon.icns`

They are Apple system artwork and are not covered by Register's MIT license. The theme applies a
page-wide grayscale filter and presents them inside a layout inspired by the original 1984
Macintosh System 1 interface.
